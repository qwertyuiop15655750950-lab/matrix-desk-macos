# 手机共享电脑代理

本工具可把电脑上已运行的 HTTP 代理通过 USB 转发或局域网提供给安卓手机。请从代理软件设置中确认 HTTP 或 Mixed 监听地址及端口；检测结果只表示候选端口可连接，不能证明手机或所有应用已成功联网。

设备授权、代理写入和恢复需要 USB 调试权限，并须在手机上允许此电脑。USB 转发、手机系统代理和应用网络支持情况都可能影响连接；该工具暂不保证整机应用流量均经过代理，也不保证连接长期稳定。

## USB 连接

1. 保持电脑代理软件运行，确认当前连接可用。将安卓手机通过 USB 连接电脑，开启 USB 调试并在手机上允许此电脑。
2. 进入工作台「手机网络」，刷新检测并勾选已授权手机。
3. 选择 USB 转发，在检测到的电脑 HTTP 代理候选中明确选择与软件设置一致的端口；软件或端口改变后重新检测。
4. 点击应用代理。工作台保存每台手机原设置，通过 USB 将手机端口转发至电脑代理端口，然后设置手机系统 HTTP 代理。
5. 点击手机浏览器出口检查，在手机浏览器中查看实际公网 IP。该按钮打开检测页面，不会把电脑的检测结果当成手机结果。

USB 模式不需要把电脑代理开放到局域网。必须保持电脑代理和 USB 连接可用；USB 断线或重连会令转发失效，手机仍保留系统代理设置，可能无法上网。刷新状态时会检查 USB 转发是否存在；失效时应重新应用或恢复原设置。

## 同一局域网连接

电脑和手机在同一局域网时，可选择局域网模式，填写电脑在该网络的 IP 地址及软件的 HTTP 或 Mixed 端口。先在代理软件中配置允许局域网访问，并确认手机能访问该地址。工作台不会自动修改电脑代理软件的共享权限。

手机不能把 127.0.0.1 作为电脑的局域网地址，它表示手机自身。检测到的局域网地址会随网络改变；端口有监听只表示候选端口可连接，仍需核对代理类型。

## 应用流量与恢复

Android 系统 HTTP 代理只影响遵守该设置的应用。有些应用使用自己的连接方式；浏览器出口正确不能证明抖音、微信等应用也使用了同一出口。需要接管完整应用流量时，应在手机安装兼容的 VPN 客户端、导入现有节点，并在手机完成首次 VPN 授权；工作台提供打开 VPN 设置的入口。不会自动批准系统授权。

多台手机共享电脑当前节点时，通常共用同一出口；这并不为每个手机分配独立 IP。节点分流规则也会影响不同目标网站的出口。

点击「恢复原设置」会恢复手机原系统代理及原有键的缺失状态，只移除本工作台新增的对应 USB 转发。原配置快照保存在本地数据库，不写进导出源码。恢复失败会逐台显示错误，保留快照供重试。

测试覆盖设备隔离、非法输入、USB 映射冲突、断线后转发失效提示、精确恢复和批量部分失败。真实手机应用的完整联网仍需 VPN 客户端适配验证。
