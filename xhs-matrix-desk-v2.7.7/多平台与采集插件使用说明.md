# 矩阵工作台 v2.8.0

桌面核心为账号、发布、人工私信、评论采集和小红书/抖音浏览计划。Android 设备控制已独立到同级 `android-device-desk` 项目，不在桌面启动时加载。素材库默认冻结，已有记录保留。

## 登录与平台隔离

在「三平台账号中心」新增账号、打开对应平台浏览器，自行扫码。小红书、抖音、视频号使用独立登录目录；小红书继续保留 20 个账号上限。账号记录、历史数据和登录目录不随源码更新被替换。

## 自有采集器

生产采集直接使用工作台自己的 Playwright 页面和本地 DOM 提取代码，不要求安装 bb-browser 或 Crawl4AI，也不会调用平台私有接口、复制登录状态或另起爬虫浏览器。这两个项目仅作为开发参考；旧通道参数仍可转到自有采集器，结果会注明。

「批量作品评论采集」支持整段分享文案、多个作品地址和对标账号主页，识别抖音 / 小红书并去重。每个主页默认读取 20 条作品，单作品最多读取 1000 条评论，本批次最多 100 个来源。混合平台必须分别选择已登录的采集账号。完整流程见「批量主页与评论采集.md」。

批量采集保存所有实际读取到的评论，美业关键词仅标记需求；未命中词、不提供用户 ID 的评论也保留。单篇关键词采集入口仍保留原筛选行为。可以保存 CSV，来源账号、作品网址和评论原文一并记录。

## 美业需求

抖音评论工作台「设置关键词」提供通用美业、美容护肤 / 皮肤管理、美甲美睫、美发 / 纹绣预设。选择后可以增删，点击保存才修改现有关键词。评论中的明确私信请求只是人工核对候选；不会自动生成发送名单或主动发送消息。

## 浏览计划

小红书、抖音各用自己的浏览器。可定义天数、每日每账号时长、时间窗口和并发数；创建后需手动开始，支持暂停、继续、停止和查看实际浏览时长。计划在当前平台页面停留、滚动，重启后暂停。不会自动点赞、评论、关注或群发，也不保证账号权重或流量改变。

## 验证范围

回归包含平台隔离、20 个小红书账号上限、分享链接去重、混合平台导入、批次暂停、部分结果保留、无外部项目时运行、评论和用户 ID 归档。实际平台选择器仍需真实账号页面校准；主页未提供发布时间时按展示顺序读取，不能假定它严格等于最新发布时间顺序。公开评论删除、折叠、限制加载或页面改版均可能影响可读取数量。

完整 48 小时在线稳定性测试尚未完成。测试和本轮窗口验证未向真实用户发消息、点赞或评论。当前验证结果见「验证记录.json」。
