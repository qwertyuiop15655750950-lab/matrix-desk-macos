# 抖音矩阵工作台：浏览器版

入口：桌面“小红书矩阵工作台.command” → 左侧“抖音工作台”。

## 已实现

- 新增、编辑抖音账号，管理分组与备注。
- 每个抖音账号使用独立 Chromium 登录目录，打开后自行扫码登录。
- 指定视频地址的浏览器只读采集，使用选定的抖音账号。
- CSV / JSON 评论导入。
- 设置关键词、筛选评论、重新筛选历史记录。
- 命中关键词后按账号与用户ID创建线索；没有用户ID的评论仅保留为评论，不用昵称冒充ID。
- 线索跟进状态、备注、查看相关评论、复制用户ID、CSV导出。
- 原有小红书账号数据保留，抖音数据使用独立表。

抖音操作统一通过浏览器，不需要开放平台应用、open_id 或 access_token。已移除官方接口采集入口。

## 使用流程

1. 新增抖音账号，点击“打开浏览器 / 扫码登录”。
2. 在浏览器里自行完成登录。
3. 在“评论采集”设置关键词，选择账号，填写完整抖音视频地址。
4. 点击“采集指定视频评论”，检查浏览器内视频与评论是否正常加载。
5. 在“线索跟进”管理命中用户，更新状态与备注。

也可导入已有评论文件：CSV表头为 `comment_id,user_id,nickname,content`；JSON为包含这些字段的评论对象数组。缺失的昵称不会自动补造。

## 当前验证范围

账号、评论和线索页面已经完成本地加载检查。数据导入、去重、筛选、跟进记录、导出和浏览器采集的数据归档通过自动化测试。

浏览器评论采集尚未使用已登录的抖音账号真机验证，选择器需要按实际抖音页面校准。当前只筛选页面已加载的评论，不保证全量采集；零条结果可能来自未登录、评论未加载、未命中关键词或页面结构变化。

直播实时采集、批量私信发送尚未实现；跟进操作保存状态与备注，不会发送消息。

## 集群及测试

`python run.py` 默认同时开启主控集群服务，与提供的源码一致，默认端口8901，可通过 `--cluster-port` 指定端口。已取消此前添加的 `--enable-cluster` 开关。

运行测试：`./venv/bin/python -m unittest discover -s tests -v`。
源码包不包含账号数据库、浏览器登录目录或虚拟环境。
