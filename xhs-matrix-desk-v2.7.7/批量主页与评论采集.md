# 批量主页、近期作品与评论

## 输入格式

可以直接粘贴抖音或小红书整段分享文案，不需要手动删掉标题、口令或文字。也可粘贴表格中的主页链接列，或导入 CSV / TXT。Excel 可另存为 CSV，或复制链接列。一次最多 100 个账号主页 / 作品链接。

支持抖音 `v.douyin.com` 分享短链、`www.douyin.com/video/...` 作品、`www.douyin.com/user/...` 主页；小红书 `explore/...` / `discovery/item/...` 作品、`user/profile/...` 主页及官方分享短链。短链只能沿官方 HTTPS 域名解析；失效或无法解析的链接会记录失败，可换完整作品网址重试。

同一作品的不同分享参数会去重。小红书访问参数用于打开原页面，界面明细和评论 CSV 保留干净作品地址；不会导出访问参数或登录信息。

## 执行

1. 在「三平台账号中心」打开小红书和抖音采集账号的浏览器，扫码登录。
2. 进入「批量作品评论采集」，点击「导入链接 / 主页表格」。
3. 为本次包含的平台分别选择采集账号，粘贴文案或链接列。每个主页作品数默认 20，单篇评论上限默认 1000；可调整。需求关键词只作标记，不过滤评论。
4. 点击「识别并创建」，检查批次后点击「开始」。同一时刻串行处理来源，已占用的账号不会混入其他浏览器任务。
5. 主页先发现公开作品，再把作品逐个加入评论队列。按主页展示顺序读取，并排除能识别的置顶标签；没有公开发布时间时会标记未核实时间，无法保证严格按日期最新。
6. 点击「来源明细」查看成功、失败、实际读取数量、上限提示和原因；点击「导出评论 CSV」获取结果。

## 停止与结果边界

工作台暂停 / 停止会阻止后续作品启动，当前作品可以通过浏览器采集面板立即停止。浏览器面板停止后，批次也会暂停，已读取评论保留。应用关闭或重启后不会自动重新开始采集。失败来源不自动反复重试，修复登录或链接后可新建批次。

v2.8.2 会检查可见网页中的登录弹窗、验证码、访问频繁提示及账号异常浏览文字提醒。遇到这些提示时，当前来源保留为待处理，并暂停正在使用同一账号的采集批次。已读评论仍会归档。人工处理页面并检查账号状态后，点击“继续”会重新读取这个来源，已存评论按原规则去重。普通作品失效仍记录失败，不与账号访问限制混为一类。

检测依赖网页文字和控件，不能识别手机客户端里的通知、图片形式的提示或所有平台页面变体。遇到网页之外的异常提醒，请手动停止计划。该功能不会处理验证码、伪装浏览器身份或保证账号不被平台限制。

读取的是当前可见并已加载的公开评论。每篇最多 1000 条、最多 20 次评论区滚动，并有等待超时；本批次最多 100 个来源。达到上限或尚未加载到末尾时，保存的是部分结果。折叠、删除或不可访问评论无法承诺全量。

导出的字段包括平台、采集账号、作品地址、原评论 ID、公开用户 ID、昵称、评论原文、命中词、归档时间。缺失 ID 留空；同名用户不合并，评论按来源和实际标识去重。不自动点赞、评论、私信或导出手机隐私数据。

## v2.8.3 域名兼容

小红书入口统一接受 `xiaohongshu.com`、`www.xiaohongshu.com`、`rednote.com`、`www.rednote.com`。插件、页面检查、主页作品发现和分享链接解析共用域名定义；同作品跨域名去重，访问所需分享参数仍保留。仅支持 HTTPS 和标准端口，伪造域名、URL 凭据和非标准端口不会进入自动操作。该补丁已用本地浏览器页面验证，实站仍待验证。
