# 矩阵工作台 v2.8.3 · 2026-10-10 更新源码

主要入口是账号管理、批量发布、数据采集。消息等辅助入口收在辅助功能中；手机管理跳转独立 Android 工作台。

## 当前更新

- 账号工作区：macOS 14+ 使用真正的内嵌 WebKit 网页。点击左侧账号直接打开，可用鼠标键盘、复制粘贴和文件选择；总览最多显示四个已打开网页，点击「进入账号」切回完整页面。账号使用独立持久化网站存储。旧 Chromium 登录目录保留；首次迁移可能需要重新扫码。其他系统保留原浏览器入口。配置独立代理的账号仍使用原浏览器，内嵌网页暂不支持独立代理。
- 发布：支持 DOCX 文案导入、保留用户标题/正文/大字报文字，依次分配到选中账号，串行处理发布任务。文字配图通过小红书平台自己的入口和已加载模板完成；生成结果与提交状态不确定时暂停等待人工确认。
- 采集：分享文案、作品链接、对标主页可批量导入；默认每主页最近 20 条作品。已读评论归档，批次可暂停恢复。遇登录、验证码、访问频繁或账号提示时停止，保留已读数据。
- 消息：显示打开/加载/失败状态，避免切换账号后的旧请求覆盖当前内容；真实平台可用性仍需逐账号核验。
- 浏览计划保留，由用户显式开始；不自动恢复。平台异常时暂停，不自动点赞、评论或群发。核心采集不依赖 bb-browser/Crawl4AI；冻结功能的外部桥接代码仍供开发参考。

## 源码运行

需要 Python 3.10+（推荐 3.12），首次安装需联网：

```sh
bash setup.sh
./venv/bin/python run.py
```

Mac 的图形界面使用 pywebview。锁定核心依赖见 requirements-mac-install.txt；内嵌功能需要 macOS 14+。源码包不包含 Python、Chromium 或账号数据。

更新原电脑：先退出该目录的工作台，再使用配套 Mac 安装包指定原目录更新。不要用空目录替换旧 data，也不要删除 venv。仅复制源码时同样保留 data、venv 和 .matrix-launch.json。
